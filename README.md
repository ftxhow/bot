# 🤖 Telegram Финансовый Бот

Телеграм-бот для управления финансами, создания анкет и отслеживания бюджета.

## 🚀 Деплой

### Render.com (Рекомендуется) ⭐
Простой деплой через GitHub:

1. Загрузите проект на GitHub
2. Подключите к [Render.com](https://render.com)
3. Добавьте `BOT_TOKEN` в Environment Variables
4. Деплой!

**Подробная инструкция**: [RENDER.md](RENDER.md)

---

## 📦 Структура проекта

```
Bot-2/
├── main.py              # Точка входа
├── global_state.py      # Настройки и токен
├── requirements.txt     # Зависимости
├── render.yaml         # Конфигурация Render
├── handlers/           # Обработчики команд
├── keyboards/          # Клавиатуры
├── states/             # FSM состояния
├── utils/              # Вспомогательные функции
└── data/               # Данные пользователей
```

## 🛠 Локальный запуск

1. Создайте файл `.env`:
   ```
   BOT_TOKEN=ваш_токен_от_BotFather
   ```

2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

3. Запустите:
   ```bash
   python main.py
   ```

## 📝 Функции бота

- ✅ Регистрация через анкету
- 💰 Отслеживание дохода и бюджета
- 🏠 Информация о доме и семье
- 📊 Просмотр и редактирование профиля
- 💾 Автоматическое сохранение данных
