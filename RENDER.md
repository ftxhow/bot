# 🚀 Запуск бота на Render.com

## Быстрая инструкция

### Шаг 1: Загрузите проект на GitHub
1. Создайте репозиторий на GitHub
2. Загрузите всю папку `Bot-2` туда
3. Или используйте GitHub Desktop

### Шаг 2: Подключите Render
1. Откройте [Render.com](https://render.com)
2. Создайте аккаунт (можно через GitHub)
3. Нажмите **"New +"** → **"Web Service"**
4. Подключите ваш GitHub репозиторий

### Шаг 3: Настройте сервис
Render автоматически обнаружит `render.yaml`, но если нужно настроить вручную:

- **Name**: telegram-bot
- **Runtime**: Python 3
- **Build Command**: `pip install -r requirements.txt`
- **Start Command**: `python main.py`

### Шаг 4: Добавьте токен
В разделе **Environment Variables**:
- **Key**: `BOT_TOKEN`
- **Value**: ваш токен от @BotFather

### Шаг 5: Деплой
1. Нажмите **"Create Web Service"**
2. Render автоматически задеплоит бота
3. Бот запустится! ✅

---

## ⚠️ Важно

**Бесплатный tier Render**:
- Засыпает после 15 минут неактивности
- Просыпается автоматически при первом сообщении боту
- Для 24/7 работы нужен платный план ($7/мес)

---

## Альтернатива: Деплой без GitHub

Если не хотите использовать GitHub:
1. Зайдите на Render
2. **"New +"** → **"Background Worker"** (вместо Web Service)
3. Загрузите код напрямую или подключите локальный Git

---

## Проверка работы

После деплоя:
1. Откройте ваш бот в Telegram
2. Отправьте `/start`
3. Бот должен ответить!

Если бот "спит" (на бесплатном тарифе), он проснётся через пару секунд после первого сообщения.
